A reference for your next maker project

Browse microcontroller and single-board computer references, OLED, LCD and e-paper display records, sensors, buttons, communication modules and power hardware. The power collection includes buck, boost, buck-boost and TP4056/TP4057 charger variants. Photos, physical pinout sources, pin-function tables and missing documentation are labeled separately.

Use the default charcoal-and-gold dark mode or switch to Light mode. Search across boards and modules, save useful boards locally, zoom diagrams and download original files. The Windows desktop edition includes its reference library for offline use.
