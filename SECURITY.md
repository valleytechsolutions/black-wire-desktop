# Security and privacy

Black Wire is an offline reference reader with a sandboxed renderer and a narrow Electron bridge. It does not need a login, telemetry service or microphone/camera permission. External source and creator links are opened in the system browser when selected. Personal records stay in Electron's user-data directory unless exported by the user.

Do not put credentials, certificate keys or personal measurement backups in issues. For a vulnerability, use GitHub's private vulnerability reporting option if the repository has enabled it; otherwise contact the maintainer through their GitHub profile before sharing exploit details publicly. Private reporting has not been claimed as configured.

Pinout correctness and electrical limits are separate from software security. Report board/revision errors with their original source and conditions.
