# Black Wire 0.5.0 / First Edition 2026

Find physical pinout sources before product photos. New connector sheets, searchable pin-purpose tables and visible coverage states explain what is documented and what still needs a map. Unified search spans boards, SBCs, devices, displays, sensors and modules with exact model ranking, keyboard navigation and scope filters. The visual layout and mobile pin tables have been refreshed.

Collection 2026.09.5 adds 46 annotated Adafruit connector-model sheets (637 modeled contacts), 58 manufacturer pin tables (633 rows), and 17 source-image attachments. 70 maker records have pin details. Of 486 maker listings, 151 have physical pinout sources, 30 have functions only, and 305 still lack both. All 2,891 board/maker listings have explicit coverage states; linked entries can represent the same hardware. No all-device or all-pin completeness claim is made. Diagrams may be partial and revision-specific; signal-name explanations do not independently verify electrical limits.

Validation: 19 unit tests; browser and mobile search/reference checks; packaged Windows x64 launch, offline images, PDF viewing, byte-exact original downloads and saved-data persistence. The Windows installer is unsigned. Clean-machine installation, Linux and macOS binaries are not validated or included. The physical First Edition book remains an unfinished editorial draft.

Manufacturer source artwork retains its own terms. Annotated Adafruit sheets and previews are CC BY-SA 3.0 adaptations; exact source and illustration hashes are retained in the collection. Older releases remain unchanged.
