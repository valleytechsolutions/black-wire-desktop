# 0.6.0 — Dark & gold workbench

The Black Wire Maker's Technical Reference Guide now opens in a warm charcoal-and-gold dark mode. Light mode is available in the top bar, and the choice persists locally. Your supplied red Black Wire logo appears in dark mode; reference images and PDFs retain their original colors.

The opening section has a new circuit design, and controls, viewers, tables and power tools share the new palette. Theme changes synchronize between browser tabs, storage restrictions are handled visibly, and direct board links now include records awaiting documentation.

The public wiki adds eight practical guides and directories covering the existing 2,405 board/device listings and 486 maker listings. All 32 wiki/directory pages are readable without JavaScript. The app and wiki have canonical metadata, social previews, structured data and a 33-URL sitemap. GitHub documentation, topics and contribution paths are refreshed.

## Downloads and validation

- Windows x64 installer; **unsigned**. Packaged native checks cover dark/light persistence, image/PDF viewing, original-file integrity, saved boards and maker search. Clean-machine installation has not been independently tested.
- Browser checks cover default/persisted themes, blocked storage, responsive layouts, keyboard search, source images, PDFs, downloads, sitemap destinations, static wiki content, structured-data syntax and root/subpath hosting. Nineteen unit tests pass.
- No verified Linux or macOS binary is attached to this release.
- The hardware catalog remains **collection 2026.09.5**. **First Edition / 2026** is unchanged. The book was not edited in this software release.

Download the installer and compare its SHA-256 with the accompanying `SHA256SUMS.txt`. Keep previous releases for reproducibility. A checksum verifies bytes; it does not make an unsigned installer signed.
