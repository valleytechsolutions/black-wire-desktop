# Project brand assets

The red Black Wire mark was supplied by the project owner as `BWM1-official.png` for dark-mode use. It is stored unchanged as `public/brand/black-wire-red.png`. The existing black-and-white mark is used in Light mode.

The supplied `VTS OFIICIAL LOGO.png` matches the existing `public/brand/valleytech.png` byte for byte (SHA-256 `704dc0daf32a201379dd2c18c7756b44fc3cf215ebcd9839cb7d6abfb7167748`). It remains unchanged and sits on a white background so its original colors are readable.

The circuit design is original CSS/SVG interface artwork. The social share card is an original layout generated by `scripts/build-social-card.mjs` with the supplied logo embedded unchanged. Project branding does not change any manufacturer artwork rights.
