# Identify displays and sensors

Use controller, interface, board revision and physical connectors to distinguish similar modules.

## Start with what you can identify

Search by the printed model, manufacturer, controller and interface. Displays & modules also filters display technology, size and resolution. OLED, LCD and e-paper describe technologies; they do not specify wiring. The same diagonal size can appear with different controllers, connectors and required support hardware.



## Compare more than the front face

1. Compare the back of the PCB, header labels, connector count and revision.
2. Check whether you have a bare panel, a breakout, a controller board or a complete display device.
3. Read the pinout for that module and interface variant.
4. Keep touch, backlight and power connections separate from the main display data bus in your notes.



## Generic names need identification

Generic and clone listings are included because makers encounter them. A family record or controller code does not guarantee a particular pin order. If identity or documentation is missing, follow the source leads and compare the actual hardware. Do not copy another vendor’s connection order simply because the modules look similar.



## Search by the connection you need

The unified search includes documented pin labels and purpose text where available. Try BME280, SSD1306, SDA, a model suffix or a brand. Pinout sources only narrows to records with a physical source map; it does not mean every contact or electrical limit has been independently approved.
