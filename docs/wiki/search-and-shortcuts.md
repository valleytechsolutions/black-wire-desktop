# Search, themes and saved boards

Use keyboard search, scope filters, dark or light mode, original downloads and workbench backups.

## Search from anywhere

Press Ctrl K on Windows or Linux, Command K on macOS, or / when you are not typing in a field. Use arrow keys to choose a result and Enter to open it. Escape closes results. Exact model matches rank first; dashes, spaces and underscores can be used interchangeably.



## Search the whole catalog

The top search combines boards, devices and maker parts, including documentation gaps. Search in selects the scope. Pinout sources only filters for physical maps. The first 30 matches are shown; add a brand or model suffix to narrow a long list. Page filters below apply to that page’s library view.



## Choose your reading environment

Dark mode is the default, with warm charcoal and gold highlights. Choose Light mode in the top bar for a warm paper background. The preference is kept locally when storage is available. Pinout images and PDFs keep their original colors in both modes.



## Read and save the source

Open a reference to zoom or fit its image. Board references also support rotation and PDF page navigation. Save original downloads the stored source file. Thumbnails and preview renders are for browsing; source notes and hashes remain with the reference.



## Back up your workbench

Use the guide’s export and import backup controls to move saved boards and personal measurements. An embedded browser can have different storage permissions from a full-screen tab. If saving is unavailable, open the guide full screen and export your workbench.
